TELEGRAM DASHBOARD — NETLIFY

The Telegram Mini App is hosted at /tg/ on the same Netlify site as the main Stock Book system. Netlify Functions handle the dashboard API, Telegram webhook and background cache worker.

Use the existing Netlify environment variables and the main system's Telegram Access Management → Enable Dashboard action after deployment is verified. Do not run an old Render configure script. See README-NETLIFY-MINIAPP.txt.
