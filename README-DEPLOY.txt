STOCK BOOK — NETLIFY DEPLOYMENT

This release is deployed to Netlify. Use the root README.md and README-NETLIFY-MINIAPP.txt.

Publish directory: .
Functions directory: netlify/functions (already configured in netlify.toml)
Node version: configured in netlify.toml

The Mini App is served at /tg/ on the same Netlify site. Do not configure the Telegram bot to the retired Render Mini App service.
